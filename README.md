# Wovant Invoice Generator

A branded invoice generator for Wovant — built with HTML, CSS, and vanilla JavaScript.

**Live:** [wovant.github.io/invoice-generator](https://wovant.github.io/invoice-generator)

## Features

- Live invoice preview as you type
- Add / remove line items with auto-calculated totals
- Discount % and Tax / VAT % support
- 8 currency options (USD, EUR, GBP, NGN, INR, CAD, AUD, ZAR)
- Status badges — Unpaid, Paid, Overdue, Draft, Partial
- Print / Save as PDF (clean A4 layout, editor hidden)
- Full Wovant brand identity — colors, typography, logo

## Usage

Open `index.html` in any browser — no build step, no dependencies.

To print or export as PDF, click **Print / Save PDF** in the top-right corner.
